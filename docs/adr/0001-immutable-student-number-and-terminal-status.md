# 学号不可变且离校态不可常规逆转

Status: accepted

系统在入学建档时统一生成全局唯一、不可变且不复用的 `StudentNo`，登录 `Account` 独立建档并绑定至学生档案；`退学` 与 `毕业` 设为不可逆终态，误操作仅允许管理员通过附带原因的冲正流程处理，不可直接切回 `在籍`。

## 备选方案

- 允许教务手工录入并后期修改学号，且账号与学号合二为一：一旦学号修改或账号变更，将破坏历史成绩单与跨上下文引用的一致性。
- 允许 `退学`、`毕业` 直接修改回 `在籍`：无法阻止离校状态期间的脏操作与在途成绩残留。

## 影响

- `Grading` 上下文以 `StudentNo` 作为稳定外键引用学生，不再受登录凭证变更影响。
- 管理员误标 `退学` 或 `毕业` 时必须通过 `ReverseEnrollmentStatus` 显式冲正并留存审计记录。
