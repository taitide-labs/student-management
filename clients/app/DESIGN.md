# 学生管理系统设计规范

支持 Desktop、Web、Mobile 与 TUI 四类平台载体，服务校内学籍档案、行政班、课程成绩与账号权限工作流；视觉参照 Linear 的静谧灰阶工作台与苹果原生分组界面，依靠字阶、极细单线分割与对齐基线建立秩序。

## 设计原则

- **结构先于装饰**：通过表面明暗层级、留白距离与极细单线分隔划分工作区，避免卡片多层嵌套与装饰性投影；数据集合直接延展至内容边界，不包裹多余空框。
- **单一强调色预算**：中性灰阶构成界面骨架，单一强调色仅用于主提交动作、当前选区与键盘焦点；语义状态色严格绑定真实业务状态，不作装饰。
- **载体原生与全键盘可达**：桌面端融合顶栏并保留系统窗控安全区，移动端遵循原生导航栈与触屏热区，终端端按字符格对齐，且核心任务均可由键盘或屏幕阅读器独立完成。
- **令牌与组件单一出口**：视觉外观由语义令牌与共享控件层统一定义，业务界面仅组合受控变体与空间秩序。

## 色彩与表面材质

- **令牌事实源**：主题配置文件 `clients/app/theme.json`（默认跟随系统外观）与客户端令牌模块 `clients/app/src/ui/token.rs`；浅色与深色模式维护完全对称的语义键集合。
- **表面层级与文本**：工作区主底面使用 `background`，常驻导航栏使用 `sidebar`，独立分组容器使用 `card`，槽底与行悬停高亮使用 `muted` 或 `accent`，弹出菜单与浮条使用 `popover`；正文使用 `foreground`，次要元数据使用 `muted-foreground`。
- **强调与状态语义**：主按钮与激活态使用 `primary`；状态色限定 `success`（正常在籍）、`warning`（挂起警示）、`destructive`（终止、危险操作与表单校验错误），其余标签统一使用中性色调。
- **边框与抬升**：基础平面区域之间仅使用 `border` 单线分隔，不施加投影；下拉浮层、模态对话框与通知浮条统一使用 `popover` 或 `card` 表面配高对比边框与投影表示层级浮起。

## 排版、空间与多端适配

### 字体、字阶与对齐

- **字体分工**：界面文本与控制标签使用平台系统界面字体；编码标识符、日期时间、度量计数与快捷键索引使用等宽字体及等宽数字对齐。
- **字阶与权重**：每屏保持三到四级字阶与两种字重，用大小、字重和 `muted-foreground` 区分主次层级，不依赖缩字号或加粗堆砌。
- **空间与同心圆角**：间距遵循紧凑四点倍阶梯，组件内边距归组件自身、组件间距归父容器，不叠加双倍留白；容器采用柔和圆角，控件使用标准 `radius`，内置徽章、滑块与高亮块采用 `radius-inset`，确保嵌套圆角同心递减。
- **对齐基线**：同层级的页眉、筛选条、数据表头、行项与空态共享同一左右内容边距脊线；混合字号行内文本按基线对齐，可比数值列右端对齐，可选状态槽位缺失时不挤压相邻列。

### 三类平台家族映射

- **Desktop 与 Web**：隐藏系统原生标题栏，将页面标识、筛选搜索与主操作融入统一首行顶栏，留出系统窗控安全区与可拖拽背景；宽窗口使用左侧常驻侧边栏配右侧工作区，采用指针紧凑密度；窗口收窄至紧凑断点时收拢为两行结构并保留全部主动作与账号退出路径，保证按钮标签完整显示不截断。
- **Mobile**：使用原生导航栈承载下钻详情与系统侧滑返回手势，底部使用贴合安全区的标签栏，输入、按钮与列表行维持标准触屏最小热区；表单弹窗自动呈现为系统抽屉。
- **TUI**：使用十六色高对比线框表面并取消圆角与投影，按整格字符对齐分割左右区域，底部常驻快捷键索引，全流程不依赖鼠标。

## 共享控件目录

共享控件层对外暴露受控的语义变体、尺寸档位、交互状态与内容槽位，支持键盘无障碍语义（明确的角色、可访问名称及禁用/选中状态暴露）：

- **表面与排版原语**：工作区画布、侧栏容器、融合顶栏、筛选条、表格列头与等列列表行、分组卡片、极细分割线、空状态引导与骨架占位，配合标题、分节标题、正文、弱化说明、等宽文本与错误提示语义排版函数。
- **按钮（Button）**：涵盖主操作、默认、线框、幽灵与危险五档变体及小、中、大三档尺寸；具备悬停亮底、按压反馈、可见外置焦点环与禁用态。
- **表单与选择（Input、LabeledField、Select、SegmentedTabs）**：统一控件高度、焦点描边与字段内联错误槽位；下拉浮层支持方向键选行与回车确认；分段标签内置滑动选区指示。
- **徽章、弹窗与通知（Badge、ModalSheet、ToastHost）**：徽章覆盖中性与语义状态色调；模态弹层支持 `Esc` 与遮罩取消，关闭后焦点自动归还触发控件；通知栈限定紧凑最大宽度，支持悬停暂停与滑动清除。
- **图标规范**：全应用统一使用单一线性图标家族与固定占位槽位；纯图标控件必须附带无障碍访问名称，不靠颜色独立传达语义。

## 壳层骨架与交互用语

- **壳层职责**：认证界面与已登录工作区严格隔离，工作区内仅呈现当前合法会话的业务视图、个人会话与安全退出动作，不添加与教务流程无关的演示入口。
- **交互用语**：导航条目使用简短名词，按钮使用明确结果的动词短语，触发弹窗或需要后续输入的命令以单字符 `…` 结尾；去除冗余括弧解释，复合元信息之间以中点 `·` 连接；仅当后台操作结果无法从当前界面变化直接察觉或发生异常时才展示通知浮条，常规登录与切页不弹提示。

## 动效清单

遵循克制即时原则，全量覆盖屏幕状态变化并在系统开启减弱动态效果时全部降级为瞬时响应：

| 状态变化分类 | 交互场景与动效策略 | 令牌与工具 | 减弱动态效果降级 |
|---|---|---|---|
| 按压与悬停 | 按钮按压轻微缩放并微调透明度；列表行与导航悬停快速背景淡入 | 缩放与透明度过渡，`fast` / `instant` 缓出 | 关闭缩放，保留瞬时底色反馈 |
| 文案或状态变更 | 状态标签切换与数字计数更新直接重绘，高频数据不叠加动画以免阅读干扰 | 无动效（语义直读优先） | 无动效 |
| 选区移动 | 分段标签与侧边栏当前项高亮指示平滑滑动或即时定位 | 位置与尺寸过渡，`base` 缓入缓出 | 瞬时切换选区 |
| 内容进出 | 页面切换即时或轻柔交叉过渡；通知浮条垂直滑入伴随淡入淡出 | 垂直位移与透明度，`fast` | 瞬时显隐 |
| 浮层与弹窗开合 | 模态弹窗与下拉菜单轻微缩放上浮展开，关闭时快速收拢 | 变换与透明度过渡，`base` 缓出 | 瞬时开合 |
| 用户触发布局变更 | 窗口跨断点收起侧栏或筛选后列表行重排即时响应，保持阅读位置稳定 | 无额外延时动画 | 无动效 |
| 拖拽与手势释放 | 移动端导航栈侧滑返回跟随系统原生手势物理曲线 | 系统原生导航过渡 | 遵循系统设置 |
| 加载与进展 | 首屏或慢请求展示静态结构匹配的骨架条；已有缓存切换直接呈现 | 静态低对比占位 | 静态占位 |
| 持续态与外观切换 | 不设置常驻呼吸装饰；切换浅深外观时禁止对控件背景做滞后颜色渐变，保证全局表面同步刷新 | 颜色即时切换 | 即时切换 |

## 推荐与禁止

- **推荐**：
  - 优先复用既有受控控件与语义变体，缺少共性表达时先扩充设计系统层再接入业务界面。
  - 在工作区数据密集区域使用带固定列头的全宽对齐列表，保证纵横扫描秩序。
  - 每次新增或修改界面均在目标载体上核对浅深双主题、键盘焦点可达性及极限窄视口表现。
- **禁止**：
  - 禁止在业务界面内使用未经过语义令牌映射的硬编码色值、字面圆角或内联样式覆盖。
  - 禁止因容器过窄而截断主操作文案，禁止在同一视图顶部叠加多层冗余标题栏。
  - 禁止为每条记录或常规静态标签滥用高饱和度彩色徽章与非语义装饰动效。
